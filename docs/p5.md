# P5 官方生态集成

官方 Runtime 锁定为 `dsh-v0.2.2-rc.5`，提交 `9c2670d3bce5275e0d1610272958121af87787bb`。本轮增加与官方构建一同打包的 `runtime/host.mjs`。Rust TUI 继续使用官方 SDK 处理会话、提示词、工具审批和结构化提问。适配层通过官方服务获取 Provider、模型、插件、Skills 和 MCP 状态。

## 配置和权限

`DSH_TUI_DSH_HOME` 指向已有 DSH 数据目录。适配层读取 `profiles/desktop/cordis.patch.yml` 和根目录 `cordis.patch.yml` 中受支持的声明式设置，根目录设置优先。支持 `agent-default-model`、`llm-deepseek`、`llm-pi-ai` 和 `mcp-manager`。Desktop 专属插件和可执行 YAML 表达式不在导入范围内。`/models` 使用 SDK 注册的路由，初始化目标仍取客户端默认值或 `DSH_TUI_PROVIDER` 与 `DSH_TUI_MODEL`。

Unix 上，若现有官方凭据文件是当前用户所有且仅所有者可访问的常规文件，独立运行目录会使用指向该文件的链接，由锁定版官方凭据插件读取。官方插件在独立目录加锁并原子替换写入目标。TUI 不解析或显示凭据。Skills 由官方加载器发现，可调用项选择后进入草稿并由用户发送。MCP 默认只显示配置和状态。启用 `DSH_TUI_ENABLE_MCP=1` 后，官方管理器可按配置建立连接。依赖 Desktop 专用插件的配置需要相应运行环境。

插件管理入口提供运行状态和 `/reload`。逐个插件安装、启停与第三方配置编辑仍由官方客户端负责。MCP 的连接配置同样由官方配置维护。

## 会话读写

官方 JSONL 持久化组件负责枚举和读取。选择当前格式的主会话后，适配层核对源版本并原子发布到独立 SDK 数据目录，已有副本继续使用。官方 SDK 对副本调用 `session/resume`，同时从持久化事件回填正文和工具输出。后续会话写入仅落在独立目录。较旧的格式可在列表中识别，当前选择器仅恢复锁定版的当前格式。历史按日期、会话 ID 和工作目录过滤。大型会话的读取和复制在后台执行，首次正文投影仍在 UI 线程。
