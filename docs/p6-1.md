# P6.1 · 终端界面重构

工作分支：`feat/p6-1-ui`。基线：`60f54bf24425bedb659dceb8fd01f17b4ff3d112`。官方 Runtime 保持 `dsh-v0.2.2-rc.5`，提交 `9c2670d3bce5275e0d1610272958121af87787bb`。

## 设计与边界

- 参考 [OpenCode TUI 源码](https://github.com/anomalyco/opencode/tree/cfbf3f717169162a505187cc578895bda1e35a11/packages/tui) 的会话框架、活动分组、输入区和选择器。Ratatui 界面保持原生；不修改官方 SDK transport、Agent、工具或会话格式。
- `dsh-state` 将可展示事件投影为用户消息、回复、工具组、推理、子会话、待办、审批、通知和错误。未识别事件不进入正文；`/debug` 从原档案逐条读取当前会话事件。归档和回放仍使用 P4 路径。
- Compact 按相邻活动聚合工具，展开先看调用和短结果，再展开单个调用看完整日志。推理、子会话及超过八个视觉行的用户消息各自折叠。
- 正文最大 108 列，F7 侧栏约 40 列且默认隐藏，窄于 100 列时自动收起。侧栏只显示已知数据，包括记录中的用量、待办和成功的文件操作；没有上报的字段不推算。
- 所有选择器共用结构化列表。共享历史的标题补全通过锁定版本的官方只读 API，限制读取体积和启动新读取的时间；历史的 F2 详情才显示完整 ID。恢复仍然使用隔离副本。
- **Markdown 解析器升级暂未实施。** 本分支保留原有按块渲染，仍会显示某些行内标记，不能按完整 CommonMark/GFM 计算验收。

## 验证

- 80×24、120×36、160×45、269×70 的 TestBackend 快照覆盖空白界面、长中文消息、工具组、浮层与侧栏。快照位于 `crates/dsh-tui/tests/goldens/`。官方 SDK PTY 测试另验收到真实工具、审批、结构化问答、子会话、隔离历史恢复和终端资源回收；模型响应用本机回归夹具，不消耗付费额度。
- macOS arm64 Release，100,000 条事件、磁盘归档：写入及投影 221.73 ms，峰值 RSS 16.1 MiB；绘制 P50/P95/P99 为 0.072/0.086/0.297 ms，滚动加绘制为 0.073/0.085/0.134 ms。P4 同类基线为 197.11 ms、15.9 MiB：本轮投影约慢 12%，内存量级不变。
- 实际 PTY 50 次编辑的按键到终端更新 P50/P95/P99 为 36.51/41.81/43.41 ms；空闲 5.02 秒无终端输出，采样 CPU 为 TUI 0.20%、SDK 0.00%。
